How to use PathMap Alchemy

About PathMap Alchemy

PathMap Alchemy runs client-side using open-weight models (Gemma) and local inference (Ollama). By eliminating server-side compute overhead, it demonstrates how open innovation enables zero-cost, privacy-first micro-SaaS tools for independent researchers.

Architecture

One static HTML file, no backend. Model calls go from your browser to Gemini, your localhost, or OpenRouter. Literature comes from PubMed E-Utilities; molecule data from PubChem and NCBI Taxonomy. Non-secret settings and your library live in this browser's localStorage. API keys are never stored: they stay in memory for this tab only and are sent only to the provider's own API URL. Sharing a result with the global library is optional and asked each time unless you choose to remember it. Based on PathMap (Apache 2.0, Joshua Dungan / Artificial General Intelligence LLC).
